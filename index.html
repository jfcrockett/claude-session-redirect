Claude session redirect

This repository publishes one static utility page. It checks a session id and opens Claude.

On GitHub Pages the path is /claude-session-redirect/cc/?s=session_…. The s parameter must be session_ followed by letters and digits, and it must appear once.

The utility page tries the Claude app, then keeps two links: Open in Claude, and Open in browser. It does not load analytics, store the id, or accept any other destination.
